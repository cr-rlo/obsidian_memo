## 소개
- 자바스크립트는 웹페이지에 생동감을 불어넣기 위해 만들어진 프로그래밍 언어
- 자바스크립트로 작성한 프로그램을 스크립트라고 하며 스크립트는 웹 페이지의 HTML안에 작성할 수 있는데, 웹 페이지를 불러올 때 스크립트가 자동으로 실행됨
- 스크립트는 특별한 준비나 컴파일 없이 문자 형태로 작성할 수 있고 실행도 가능
- 자바스크립트는 브라우저뿐만 아니라 서버에서도 실행할 수 있음
	- 이 외에도 자바스크립트 엔진 프로그램이 들어있는 모든 디바이스에서 동작
- 브라우저에는 자바스크립트 가상 머신이라 불리는 엔진 내장
	- V8: chrome과 opera
	- SpiderMonkey: firefox
	- Trident, chakra: IE
## 엔진의 동작 원리
1. 엔진(브라우저 내장 엔진)이 스크립트를 읽음(파싱)
2. 읽어 들인 스크립트를 기계어로 전환(컴파일)
3. 기계어로 전환된 코드가 실행 => 기계어로 전환되었기 때문에 실행 속도가 빠름
- 엔진은 프로세스 각 단계마다 최적화 진행
- 컴파일이 끝나고 실행 중인 코드를 감시하면서, 이 코드로 흘러가는 데이터를 분석하고 분석 결과를 토대로 기계어로 전환된 코드를 다시 최적화하기도 함
## 브라우저에서 할 수 있는 일과 없는 일
- 할 수 있는 일
	- 페이지에 새로운 HTML을 추가하거나 기존 HTML, 혹은 스타일 수정하기
	- 마우스 클릭이나 포인터의 움직임, 키보드 키 눌림 등과 같은 사용자 행동에 반응하기
	- 네트워크를 통해 원격 서버에 요청을 보내거나, 파일 다운로드, 업로드하기
	- 쿠키를 가져오거나 설정하기, 사용자에게 질문을 건네거나 메시지 보여주기
	- 클라이언트 측에 데이터 저장하기(로컬 스토리지)
- 브라우저에서 할 수 없는 일
	- 웹 페이지 내 스크립트는 디스크에 저장된 임의의 파일을 읽거나 쓰고, 복사하거나 실행할 때 제약을 받을 수 있음 => 운영체제가 지원하는 기능을 브라우저가 직접 쓰지 못하게 막혀있기 때문
	- 카메라나 마이크 같은 디바이스와 상호작용하려면 사용자의 명시적인 허가가 있어야 함
	- 브라우저 내 탭과 창은 대개 서로의 정보를 알 수 없음 그런데 자바스크립트를 사용해 한 창에서 다른 창을 열 때는 예외 발생 => 이 경우에도 도메인이나 프로토콜, 포트가 다르다면 페이지에 접근할 수 없음
	- 타 사이트나 도메인에서 데이터를 받아오는 것은 불가능 혹은 원격 서버에 명확히 승인을 해줘야 함
## 자바스크립트만의 강점
- HTML/CSS와 완전히 통합할 수 있음
- 간단한 일은 간단하게 처리할 수 있게 해줌
- 모든 주요 브라우저에서 지원하고, 기본 언어로 사용됨
## 자바스크립트 기본
- 자바스크립트 코드의 양이 많은 경우엔, 파일로 소분하여 저장할 수 있음
-  `<`script  `src` `= "`/path/to/script.js`"` >`  `</`script >`
	- 분해해 놓은 각 파일은 src 속성을 통해 HTML에 삽입함
	- src에는 파일 경로나 URL이 들어갈 수 있음
## 코드 구조
- statement 문
	- 문은 어떤 작업을 수행하는 문법구조와 명령어
	- 서로 다른 문은 세미콜론으로 구분함
	- 줄 바꿈이 있으면 세미콜론이 자동으로 존재한다고 가정
## 엄격 모드
- ES5가 등장하면서 새로운 기능이 추가되고 기존 기능 중 일부가 변경됨
- 기존 기능을 변경하였기 때문에 하위 호환성 문제 발생 -> 변경 사항 대부분은 ES5기본 모드에선 활성화 되지 않도록 설계
- 대신 Use strict라는 특별한 지시를 통해 엄격모드를 활성화 했을 때만 이 변경사항이 활성화되게 해둠
- use strict라는 지시자가 최 상단에 오면 스크립트 전체가 모던한 방식으로 동작함
- 일단 엄격 모드가 적용되면 돌이킬 방법은 없음
- 코드를 클래스와 모듈을 사용해 구성하면 자동으로 적용되기에 이를 생략해도 됨
## 변수와 상수
- 변수는 데이터를 저장할 때 쓰이는 이름이 붙은 저장소 => 온라인 쇼핑몰 애플리케이션을 구축하는 경우 상품이나 방문객 등의 정보를 저장할 때 변수를 사용함
- let
	- let message = 'hello';
	- 변수는 한 번만 선언해야 함
	- 같은 변수를 여러 번 선언하면 에러가 발생
- var
	- let과 거의 동일하게 동작
- 변수명에는 오직 문자와 숫자, 그리고 기호 $과 _ 만 들어갈 수 있음
- 변수명은 숫자로 시작해서는 안되고 하이픈을 사용할 수 없음
- 예약어 목록에 있는 단어 역시 변수명으로 사용할 수 없음

- 상수
	- 변화하지 않는 변수를 선언할 때 사용
	- const message = 'hello';
	- 상수는 재할당할 수 없으므로 상수를 변경하고자 하면 에러 발생
	- 대문자 상수는 하드 코딩한 값의 별칭을 만들 때 사용
## 자료형
- 자바스크립트의 변수는 자료형에 관계없이 모든 데이터일 수 있음
- 따라서 변수는 어떤 순간에 문자열일 수 있고 다른 순간엔 숫자가 될 수도 있음
- 자료의 타입은 있지만 변수에 저장되는 값의 타입은 언제든지 바꿀 수 있는 동적 타입언어
- 숫자형
	- 숫자형은 정수 및 부동소수점 숫자를 나타냄
	- 숫자형과 관련된 연산은 다양한데, 곱셈, 나눗셈, 덧셈, 뺄셈 등이 대표적
	- 숫자형에는 일반적인 숫자 외에 Infinity, -Infinity, NaN과 같은 특수 문자값이 포함됨 
	- Infinity
		- 어떤 숫자보다 더 큰 특수 값 무한대
		- 어느 숫자든 0으로 나누면 무한대를 얻을 수 있음
	- NaN
		- 계산 중에 에러가 발생했다는 것을 나타내주는 값
		- 부정확하거나 정의되지 않은 수학 연산을 사용하면 계산 중에 에러가 발생하는데 이때 NaN이 반환됨
- BigInt
	- 내부 표현 방식 때문에 자바스크립트에서는 숫자형으로 나타낼 수 없는 범위가 있음
	- 위 자료형은 길이에 상관없이 정수를 나타낼 수 있음
	- BigInt 값은 정수 리터럴 끝에 n을 붙이면 만들 수 있음
- 문자형
	- 문자열을 따옴표로 묶어서 나타냄
	- 큰 따옴표와 작은 따옴표는 차이를 두지 않음
	- 백틱으로 변수나 표현식을 감싼 후 ${ }안에 넣어주면 원하는 변수나 표현식을 문자열 중간에 손쉽게 넣을 수 있음
	- ${ } 안에는 변수나 수학 관련 표현식을 넣을 수 있음
- 불린형
	- true와 false 두 가지 값밖에 없는 자료형
	- 긍정이나 부정을 나타내는 값을 저장할 때 사용함
	- 비교 결과를 저장할 때도 사용됨
- null값
	- 어느 자료형에도 속하지 않는 값
	- null 값은 오로지 null값만 포함하는 별도의 자료형을 만듦
- undefined 값
	- null처럼 자신만의 자료형을 형성
	- 변수는 선언했지만 값을 할당하지 않았을 때
	- 개발자가 변수에 undefined를 명시적으로 할당하는 것도 가능
- 객체와 심볼
	- object(객체)형은 특수한 자료형
	- 객체형을 제외한 다른 자료형은 문자열이든 숫자든 한 가지만 표현할 수 있기 때문에 원시 자료형이라고 부름
	- 반면 객체는 복잡한 개체나 데이터 컬렉션을 표현할 수 있음
	- 심볼형은 객체의 고유한 식별자를 만들 때 사용됨 
- typeof 연산자
	- 인수의 자료형을 반환
	- 변수의 자료형을 빠르게 알아내고자 할 때 혹은 자료형에 따라 처리 방식을 다르게 하고 싶을 때 유용
	- typeof x를 호출하면 인수의 자료형을 나타내는 문자열을 반환
	- typeof null의 결과는 object
		- null은 별도의 고유한 자료형을 가지는 특수 값으로 객체가 아니지만 하위 호환성을 유지하기 위해서 이렇게 출력됨 => 실제로는 객체가 아님
## alert, prompt, confrim을 이용한 상호작용
- alert
	- 이 함수가 실행되면 사용자가 확인(OK)를 누를 때까지 메세지를 보여주는 창이 계속 떠있게 됨
	- 메시지가 있는 창은 모달 창이라고 부름
	- 확인 버튼을 누르기 전까지는 모달 창 바깥에 있는 버튼을 누른다거나 하는 행동을 할 수 없음
- prompt
	- 브라우저에서 제공하는 prompt 함수는 두 개의 인수를 받음
	- prompt(title, [ default ])
	- 함수가 실행되면 텍스트 메시지와 입력필드, 확인, 취소 버튼이 있는 모달 창을 띄워줌
	- title: 시용자에게 보여줄 문자열
	- default: 입력 필드의 초깃값(선택값)
- confirm
	- confirm 함수는 매개변수로 받은 질문과 확인 및 취소 버튼이 있는 모달 창을 보여줌
	- 사용자가 확인 버튼을 누르면 true, 그 외의 경우는 false를 반환함
## 형 변환
- 함수와 연산자에 전달되는 값은 대부분 적절한 자료형으로 자동 변환됨
- alert가 전달받은 값의 자료형과 관계없이 이를 문자열로 자동 변환하여 보여주는 것이나, 수학 관련 연산자가 전달받은 값을 숫자로 변환하는 경우가 형 변환의 대표적인 예시
- 문자형으로 변환
	- alert 메서드는 매개변수로 문자형을 받기 때문에 alert(value)에서 value는 문자형이어야 함
	- 다른 형의 값을 전달받으면 이 값은 문자형으로 자동 변환됨
	- String(value) 함수를 호출해 전달받은 값을 문자열로 변환할 수도 있음
- 숫자형으로 변환
	- 숫자형이 아닌 값에 나누기를 적용한 경우와 같이 수학과 관련된 함수와 표현식에서 자동으로 일어남
	- Number(value)함수를 이용하면 주어진 값을 숫자형으로 명시해서 변환할 수 있음
	- 숫자 이외의 글자가 들어가 있는 문자열을 숫자형으로 변환하려고 하면 그 결과는 NaN이 됨
	- undefined는 NaN
	- null은 0
	- true and false는 1과 0
	- string은 일단 문자열의 처음과 끝 공백이 제거되고 남아있는 문자열이 없다면 0, 그럴지 않다면 문자열에서 숫자를 읽음
- 불린형으로 변환
	- Boolean(value)를 호출하면 명시적으로 불리언으로의 형 변환을 수행할 수 있음
	- 숫자 0, 빈 문자열, null, undefined, NaN과 같이 직관적으로도 비어있다고 느껴지는 값들은 false가 되고 그 외의 값은 true로 변환됨
	- 문자열 "0"은 true
## 기본 연산자와 수학
- 피연산자
	- 연산자가 연산을 수행하는 대상. 이는 인수라는 용어로 불리기도 함
	- 피연산자를 하나만 받는 연산자는 단항 연산자
	- 피연산자의 부호를 뒤집는 단항 마이너스 연산자 -는 단항 연산자의 대표적인 예
- 이항 연산자
	- 두 개의 피연산자를 받는 연산자는 이항 연산자라고 부름
	- 마이너스 연산자는 이항 연산자로도 쓸 수 있음
- 수학
	- 나머지 연산자 %
		- a % b는 a를 b로 나눈 후 그 나머지를 정수로 반환해 줌
	- 거듭제곱 연산자 **
		- a ** b 를 하면 a를 b번 곱한 값이 반환
- 이항 연산자와 문자열 연결
	- 덧셈 연산자는 대개 숫자를 더한 결과를 반환
	- 이항 연산자 +의 피연산자로 문자열이 전달되면 덧셈 연산자는 덧셈이 아닌 문자열을 병합함
	- 따라서 이항 연산자를 사용할 때는 피연산자 중 하나가 문자열이면 다른 하나도 문자열로 변환된다는 점에 주의하기 
	- 이항 덧셈 연산자는 문자열 연결과 변환이라는 특별한 기능을 제공함
	- 다른 산술연산자가 오직 숫자형의 피연산자만 다루고, 피연산자가 숫자형이 아닌 경우에 그 형을 숫자형으로 바꾸는 것과는 대조적
- 2 + 2 + '1'
	- 그러나 위와 같은 경우에서는 '41'이 출력됨
	- 연산이 왼쪽에서 오른쪽으로 순차적으로 진행되기 때문에 두 개의 숫자 뒤에 문자열이 오는 경우 숫자가 먼저 더해지고 그 후 더해진 숫자와 문자열의 병합이 일어남
- 단항 덧셈 연산자
	- 숫자에는 아무 영향도 미치지 않음
	- 숫자형이 아닌 피연산자는 숫자형으로 변환함
- 연산자 우선순위
	- 동일한 기호의 단항 연산자는 이항 연산자보다 우선순위가 높다
- 할당 연산자
	- 무언가를 할당할 때 쓰이는 =도 연산자
	- 우선순위는 아주 낮음

## if와 ?를 사용한 조건 처리
- if문
	- 괄호 안에 들어가는 조건을 평가하는데, 그 결과가 true이면 코드 블럭이 실행됨
	- 조건이 true일 때 복수의 문을 실행하고 싶다면 중괄호로 코드 블록을 감싸야 함
	- 그러나 한 줄 이더라도 중괄호로 감싸면 가독성이 올라가서 좋음
- 불린형으로의 변환
	- if(...)문은 괄호 안의 표현식을 평가하고 그 결과를 불린값으로 변환함
	- 숫자 0, 빈 문자열, null, undefined, NaN은 불린형으로 변환 시 모두 false가 됨 => 이런 값들은 falsy라고 부름
	- 이 외의 값은 불린형으로 변환시 모드 true가 되므로 truthy라고 부름
- else 절
	- if 문엔 else 절을 붙일 수 있음
	- else 뒤에 이어지는 코드 블록은 조건이 거짓 일 때 실행됨
- else if로 복수 조건 처리하기
	- 유사하지만 약간씩 차이가 있는 조건 여러 개를 처리해야 할 때 사용
- 조건부 연산자 ?
	- 조건에 따라 다른 값을 변수에 할당해줘야 할 때
	- 물음표 연산자라고도 불리는 조건부 연산자를 사용하면 식을 간결하게 표현가능
	- 조건부 연산자는 ?로 표시
	- 피연산자가 세 개이기 때문에 조건부 연산자를 삼항 연산자라고 부르는 사람도 있음
- 다중 ?
	- 물음표 연산자 여러개를 연결하면 복수의 조건을 처리할 수 있음
## 논리 연산자
- ||(OR)
	- 불린값을 조작하는 데 쓰임
	- 인수 중 하나라도 true이면 true
	- 피연산자가 불린형이 아니면 평가를 위해 불린형으로 변환
	- OR 연산자와 피연산자가 여러 개인 경우에는 첫 번째 truthy를 반환하고 피연산자에 truthy가 하나도 없다면 마지막 피연산자를 반환
- &&(AND)
	- 두 피연산자가 모두 참일 때 true를 반환
	- AND 연산자와 피연산자가 여러 개인 경우 첫 번째 falsy를 반환
	- 피연산자에 falsy가 없다면 마지막 값을 번환
- AND의 우선순위가 ||보다 높음
- !(NOT)
## nullish 병합 연산자 ??
- ??를 사용하면 짧은 문법으로 여러 피연산자 중 그 값이 확정되어있는 변수를 찾을 수 있음
- null이나 undefined가 아닌 첫 번째 피연산자
- ||과 가장 큰 차이는 ||은 0을 falsy로 취급하여 null이나 undefined를 할당한 것과 동일하게 처리하지만 ??은 0이라는 변수가 할당된 것으로 보아 0이 출력됨
- ??의 연산자 우선순위는 5로 꽤 낮음
- 따라서 ??는 =와 ?보다는 먼저, 대부분의 연산자보다는 나중에 평가됨
## while과 for 반복문
- while 반복문
	- while (condition) { // 코드(반복문 본문이라고 불림) }
	- condition 조건이 truthy면 반복문 본문의 코드가 실행됨
- do while 반복문
	- do while 문법을 사용하면 condition을 반복문 본문 아래로 옮길 수 있음
	- do { // 반복문 본문 } while (condition)
- for 반복문
	- for(begin; condition; step) { //반복문 본문 }
	- begin
		- 반복문에 진입할 때 단 한 번 실행됨
	- condition
		- 반복마다 해당 조건이 확인됨
		- false이면 반복문을 멈춤
	- body
		- 반복문 본문
		- condition이 truthy일 동안 계속해서 실행됨
	- step
		- i++
		- 각 반복의 body가 실행된 후 실행됨
	- begin을 실행함 -> condition이 truthy -> body 실행 -> step 실행 위 과정 반복
	- 구성요소 생략하기
		- 반복문이 시작될 때 아무것도 할 필요가 없으면 begin을 생략하는 것이 가능
		- step 역시 생략 가능
		- 모든 구성요소를 생략하는 것도 가능하지만 for( ;; )이렇게 세미콜론을 넣어줘야 함
- 반복문 빠져나오기
	- break를 사용하면 언제든 원하는 때에 반복문을 빠져나올 수 있음
	- 반복문이 증시 중단되고 제어 흐름이 반복문 아래 첫 번째 줄로 이동
- 다음 반복으로 넘어가기
	- continue
	- 전체 반복문을 멈추지 않고 현재  실행 중인 이터레이션을 멈추고 반복문이 다음 이터레이션을 강제로 실행시키도록 함
- labelName: for (...) { }
	- 레이블은 반복문 앞에 콜론과 함께 쓰이는 식별자
	- if (!input) break label;
	- 레이블이 붙은 반복문을 찾고 해당 반복문을 빠져나오게 해줌
- for (let i = 2; i <=10; i++){ if (i % 2 == 0) {alert( i );} }
	- 반복문을 사용해서 2부터 10까지 숫자 중 짝수만 출력하는 것
- let i = 1; while ( i<3 ){ alert ( `number ${i}!`); i++; }
- 소수 출력하기
	- n = prompt( 숫자를 입력해주세요, 0);
	- nextPrime: for (let i = 2; i<= n; i++ ){ for (let j = 2; j <i; j++ ) { if ( i % j == 0 ) continue nextPrime; } alert( i ); }
		- 소수는 1과 그 수 자신 이외의 자연수로는 나눌 수 없는 자연수가 소수
		- continue를 통해서 j반복문을 멈추고 다음 반복문 i로 넘어감
## switch문
- 복수의 if 조건문은 switch문으로 바꿀 수 있음
- switch문은 하나 이상의 case문으로 구성됨
- 대개 default문도 있지만 필수는 아님
- switch( x ) { case 'value 1': ... [ break ;] case 'value 2': ... [ break ;] default:  }
	- 변수 x값과 첫 번째 case문의 값 value1을 비교한 후 두 번째 case문의 값 value2와 비교 => 위 과정 반복
	- case문에서 변수 x의 값과 일치하는 값을  찾으면 해당 case문의 아래 코드가 실행됨
	- 이때, break문을 만나거나 switch 문이 끝나면 코드의 실행은 멈춤
	- 값과 일치하는 case문이 없다면 default가 실행( default문이 있는 경우 )
- case 문에 break문이 없는 경우
	- 조건에 부합하는지 여부를 따지지 않고 이어지는 case문을 실행
## 함수
- 함수 선언
	- function 함수명 ( ) { }
	- 괄호 안에는 매개변수가 들어감
	- 새롭게 정의한 함수는 함수명( ); 이렇게 호출할 수 있음
- 지역 변수
	- 함수 내에서 선언한 변수인 지역변수는 함수 안에서만 접근할 수 있음
- 외부 변수
	- 함수 내부에서 함수 외부 변수는 접근할 수 있음
	- 함수에서는 외부 변수에 접근하는 것뿐만 아니라 수정도 할 수 있음
	- 외부 변수는 지역 변수가 없는 경우에만 사용할 수 있음
	- 함수 내부에 동일한 이름을 가진 변수가 선언되었다면 내부 변수는 외부 변수를 가림
- 매개 변수 
	- 임의의 데이터를 함수 안에 전달할 수 있음
- 반환값
	- 함수를 호출했을 때 함수를 호출한 그곳에 특정 값을 반환하게 할 수 있음
	- 이때 이 특정 값을 반환 값이라고 부름
	- 지시자 return만 명시하면 함수 즉시 종료
## 함수 표현식
- 함수를 생성하고 변수에 값을 할당하는 것처럼 함수가 변수에 할당됨
- 콜백함수
	- 함수를 함수의 인수로 전달하고 필요하다면 인수로 전달한 그 함수를 나중에 호출하는 것이 콜백함수의 개념
- 함수 표현식은 실제 실행 흐름이 해당 함수에 도달했을 때 함수 생성 => 실행 흐름이 함수에 도달했을 때부터 함수를 사용할 수 있음
- 함수 선언문은 함수 선언문이 정의되기 전에도 호출할 수 있음
	- 따라서 전역 함수 선언문은 스크립트 어디에 있느냐에 상관없이 사용할 수 있음
## 화살표 함수 기본
- let func = (arg1, arg2, ...argN) => expression

	- 그리고 return 지시자를 사용해 명시적으로 결괏값을 반환해줘야 함

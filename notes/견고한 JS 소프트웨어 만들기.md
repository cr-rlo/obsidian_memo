## 아리송한 상황들
- 문자와 숫자 더하기 연산 
	- 숫자가 문자로 변환하게 됨
	- '1' + 1 = '11'
- 문자와 숫자 곱하기 연산
	- 문자가 숫자로 변환하기 됨
	- '2' * 3 = 6
- 연산자 우선순위
	- 곱하기 먼저 실행
	- 1 + '2' + 3 * 4 = '1212'
	- 3 * 4 = 12
	- 1 + '2' = '12'
	- '12' + 12 = '1212'
- 자바스크립트는 컴파일러가 없기 때문에 직접 실행하여 테스트하는 것이 최선
## 몇 가지 테스트 개념들
- 단위 테스트(unit test)
	- 특정 조건에서 어떻게 작동해야 할지를 정의한 것을 단위라고 함
	- 대개 함수로 표현 즉, 함수를 테스트 하는 것을 단위 테스트라고 함
	- 준비 -> 실행 -> 단언 패턴을 따름
		- 인풋을 준비하는 단계
		- 인풋을 전달해서 함수를 실행하는 단계
		- 결과를 검증하는 단계
	- 테스트 주도 개발(TDD)
		- 기능을 테스트할 수 있는 테스트 코드를 만듦(단위 테스트)
		- 적색 녹색, 리팩터 순환
			- 실패하는 테스트 코드를 만드는 단계를 적색단계
			- 테스트에 통과할 정도로 기능코드를 작서하는 녹색단계
			- 추상화하고 확장가능하며 중복되지 않은 소프트웨어 공학 원칙에 맞는 코드를 작성하는 리팩터 단계
		- 테스트하기 쉬운 코드
		- 관심사의 분리

## 테스트 할 수 없는 코드
- < button onclick= "counter++; countDisplay()"> 증가 < /button>
	- 관심사가 분리되지 않았음
	- 클릭 이벤트 처리기를 인라인 형태로 정의한 점
	- 하나의 코드는 하나의 역할만 해야한다는 단일 책임 원칙을 위배
- var counter = 0;
	- 재사용성이 떨어짐
	- counter로 전역 공간을 어지럽힌 점
- var el = document.getElementById("counter-display");
	- 횟수를 표시하는 span id를 displayCount 함수에서 하드 코딩한 점
	- open close 원칙 위배
		- 확장에는 열려있고 변경에는 닫혀있어야한다는 원칙
- 모듈 패턴
	- 개발자들이 자주 쓰는 해결 방법을 패턴이라고 함
	- 자바스크립트 같은 경우 문제해결에 가장 많이 사용되는 패턴이 바로 모듈 패턴
	- 모듈 패턴이란 함수로 데이터를 감추고, 모듈 API를 담고 있는 객체를 반환하는 형태
	- 1. 임의 함수를 호출하여 생성하는 모듈
		- var App = App || {}
			- App라는 네임 스페이스를 만듦
		- App.Person = function(God){ var name = God.makeName()
		- }
			- 네임 스페이스에 Person이라는 모듈, 함수 추가
			- 의존성 있는 God 함수를 주입
			- God 모듈이 name을 만들어내는 역할
		- Return { getName: function() {return name}, setName: function(newName) {name = newName}}
			- getName과 setName이라는 메소드로 이뤄진 객체 반환하는 함수
			- name 변수는 모듈 안에서만 접근 가능하도록 되어있음
			- 리턴되는 객체의 메서드 즉 getName과 setName에서 사용하기 때문에 클로즈 변수로 저장

	- 2. 즉시 실행 함수 기반의 모듈
		- 임의 모듈 패턴과 매우 유사
		- 다른 점은 모듈을 정의한 직후에 바로 객체를 생성한다는 점
		- 싱글톤 인스턴스에서 사용
		- var App = App || { }
		- App.Person = (function ( ) { let name = "" 
		- return { getName(God) { name = name || God.makeName( ) 
		- return name }, 
		- setName(newName) { name = newName } } })
- 모듈 생성 원칙
	- 모듈 패턴을 사용하려면 두 가지 원칙을 잘 지켜야 함
	- 1. 단일 책임 원칙에 따라 모듈은 한 가지 역할만 한다.
	- 2. 모듈 자신이 사용할 객체가 있다면 의존성 주입 형태로 제공한다.
		- 또는 팩토리 주입 형태로 제공한다

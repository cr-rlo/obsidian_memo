## 함수형 자바스크립트 기본기
- 평가
	- 코드가 계산되어 값을 만드는 것
- 일급
	- 값으로 다룰 수 있다.
	- 변수에 담을 수 있다.
		- const a = 10;
	- 함수의 인자로 사용될 수 있다.
		- const add10 = a => a + 10;
	- 함수의 결과로 사용될 수 있다.
		- const r = add10(a);
		- log(r);
- 일급 함수
	- 함수를 값으로 다룰 수 있다.
		- const add5 = a => a + 5;
		- 이 변수에 함수를 값으로 다루어서 담을 수 있다는 말
		- log(add5);
		- log(add5(5));
		- 함수의 결과값으로 함수가 사용될 수 있다는 말
			- const f1 = () => () => 1;
			- log(f1( ));
				- ( ) => 1 출력
			- f1이라는 함수는 실행됐을 때 다시 함수를 리턴할 수 있음
		- 함수를 인자 값으로 다룬다의 의미
			- 일반적으로 함수를 쓸 때는 숫자를 인자로 넘긴다.
			- 함수를 인자 값으로 다룬다는 것은 어떤 함수를 실행할 때 다른 함수를 통째로 던져준다는 뜻
			- 
	- 조합성과 추상화의 도구

- 고차 함수
	- 함수를 값으로 다루는 함수
	- 일급 함수의 성질을 이용
	- 크게 두 가지가 있음
		- 함수를 인자로 받아서 실행해주는 함수
			- const apply1 = f => f(1);
			- const add2 = a => a + 2;
			- apply1이라는 함수는 함수를 받아서 함수에 1을 적용하는 함수
			- 함수가 함수를 받아서 안에서 실행하고 있기 때문에 함수를 인자 값으로 다루고 있기 때문에 고차 함수라고 말함
				- log(apply1(add2)); => 3

			- const times = ( f, n ) => { let i = -1; while (++i < n) f( i ); }
			- times(log, 3);
				- 함수와 숫자를 받아서 이 숫자만큼 이 함수를 실행하는 함수
				- 
		- 함수를 만들어서 리턴하는 함수(클로저를 만들어서 리턴하는 함수)
			- 클로저는 함수가 a값을 계속 기억하고 있다는 뜻
			- 고차 함수가 내부 함수를 생성하고 그 함수를 반환할 때, 반환된 함수가 외부 함슈의 환경(변수)를 기억하고 있다는 의미
			- const addMaker = a => b => a+b;
				- function(a){ return function(b) { return a + b;}; };
			- const add10 = addMaker(10);
				- 매개 a자리에 숫자 10이 들어감
				- 함수 내부는 b => 10 + b라는 알맹이를 가진 새로운 함수가 됨
				- 따라서 add10에는 이 함수 변수 그대로 저장
			- log(add10); => b => 10+b
			- log(add10(5)); => 15
			- 자바스크립트에서는 내부함수가 외부 함수의 변수 a를 참조하고 있으면 외부 함수의 실행이 끝나도 그 변수를 클로저 공간에 따로 박제해서 보관함 따라서 add10은 언제 어디서 실행되어도 자기가 태어날 때 받았던 10을 기억하고 활용함
## ES6에서의 순회와 이터러블: 이터레이터 프로토콜
- 기존과 달라진 ES6에서의 리스트 순회
	- 기존 방식
		- for (var i = 0; i < list.length; i++){ log(list[i]); }
			- 리스트 혹은 array라는 값에 length라는 프로퍼티에 의존해서, 숫자라는 키로 해당하는 내부의 값을 숫자라는 키로 순회하도록 i를 증가시켜주면서 length만큼 숫자키로 접근해서 리스트 안에 있는 값을 순회하는 방식
		- const str = 'abc';
		- for (var i = 0; i < str.length; i++){log(str[i]);}
	- ES6의 순회방식
		- for (const a of list) { log( a ); }
		- for (const a of str) {log( a ); }
		- const 는 값을 바꿀 수 없는 상수를 선언할 때 사용
		- 반복문인데 const를 써도 에러가 나지 않는 이유는 for문이 돌 때 컴퓨터는 기존 a라는 변수의 값을 수정하는 것이 아니라 매 회차 회전할 때마다 완전히 새로운 a라는 상수를 독립적으로 새로 만들기 때문
## Array, Set, Map을 통해 알아보는 이터러블/ 이터레이터 프로토콜
- 자바스크립트에는 array, set, map 이라는 내장 값들을 가지고 있음
	- iterable iterator 프로토콜을 따르고 있음
	- iterable은 iterator을 return하는 Symbol.iterator 메서드를 가진 값이라는 의미
	- iterator은 {value, done} 객체를 리턴하는 next()값을 가진 값
		- 이터레이터는 iterator.next()라는 메서드를 가졌고 이 메서드를 실행했을 때 value와 done을 가지고 있는 객체를 return하는 값
			- iterator.next() => {value:1, done:false};
		- 이터러블/ 이터레이터 프로토콜은 이러한 이터러블을 for of문이나 전개연산자 등과 함께 동작하도록 한 규약
- 이 값들을 모두 for of 문으로 순회할 수 있음
- Array를 통해 알아보기 
	- const arr = [1,2,3];
	- for ( const a of arr ) { log(a); }
		- arr같은 경우에 arr[0]과 같이 키로 접근해서 안에 있는 값을 조회할 수 있음
		- 
- Set을 통해 알아보기
	-  const set = new Set( [1,2,3] );
	- for ( const a of set ) { log(a); }
		- set은 set[0]으로 조회할 수 없음
		- 
- Map을 통해 알아보기
	-   const map = new Map( ['a', 1], ['b', 2], ['c', 3] );
	- for ( const a of map ) { log(a); }
		- map역시 map[0]으로 조회할 수 없음
		- map.values()하면 value값만 뽑아줌
		- map.keys()는 key값
- Symbol.iterator
	- 이 symbol은 어떤 객체의 키로 사용될 수 있음
	- arr[Symbol.iterator] 을 해보면 values()가 출력
	- set과 map역시 마찬가지(map은 entries( ))
## 사용자 정의 이터러블, 이터러블/ 이터레이터 프로토콜 정의
- const iterable = { [Symbol.iterator] ( ){ return { next( ){ return { value, done } }}  } }
	- 이 이터러블 값은 Symbol iterator 메서드를 구현하고 있어야 함
	- 그리고 그 메서드는 iterator을 반환해야 함
	- iterator은 next를 메서드로 가지고 있으며 next는 value와 done을 가지고 있는 객체를 return해야 함
- const iterable = { [Symbol.iterator] ( ){ let i = 3; return { next( ){ return i == 0 ? { done: true } : { value: i--, done: false } }}  } };
	- let iterator = iterable[Symbol.iterator] ();
	- log(iterator.next());
	- 그렇다는 얘기는 이 iterable을 순회할 수 있다는 의미
		- for(const a of iterable) log(a);

- const arr2 = [1,2,3];
- let iter2 = arr2[Symbol.iterator] ();
- iter2.next( );
- for (const a of iter2) log(a);
	- 잘 구현된 iterable(array)의 경우에는 iterator을 만들어서 이 이터레이터를 반복문에 집어 넣었을 때 순회가 제대로 됨
	- 그리고 일부 진행했을 때 진행한 이후의 값들로만 또 순회를 할 수가 있음
		- 중간에 next메서드를 사용한 경우
	- iter2 역시 Symbol.iterator을 가지고 있음
	- 그리고 이 symbol.iterator을 실행한 값은 자기 자신임 
		- iter2[Symbol.iterator] ( ) == iter2
	- 이렇게 이터레이터가 자기 자신을 반환하는 symbol.iterator 메서드를 가지고 있을 때 well-formed iterator, well-formed iterable이라고 할 수 있음
	- 
- 위에 우리가 만든 이터러블, 이터레이터를 웰 폼드 이터레이터를 반환할 수 있도록 하기 위해서는 
- const iterable = { [Symbol.iterator] ( ){ let i = 3; return {<mark style="background: #FFF3A3A6;"> next( ){ return i == 0 ? { done: true } : { value: i--, done: false }; }, [Symbol.iterator] ( ) {return this;} }  } };</mark>
	- 마지막 부분에 심볼 이터레이터를 실행했을 때 반환한 이터레이터가 자기 자신 또한 이터러블이면서 또 심볼 이터레이터를 실행했을 때 자기자신을 리턴하도록 해서 중간에 다시 for of문 같은 곳에 들어간다거나 어디서든 이렇게 심볼 이터레이터 메서드로 이터레이터로 만들었을 때 이전까지 진행되어 있던 자기의 상태에서 계속해서 넥스트를 할 수 있도록 만들어 둔 것이 웰폼드 이터레이터 임

## 제너레이터와 이터레이터
- 제너레이터는 이터레이터이자 이터러블을 생성하는 함수
- 즉 제너레이터는 이터레이터를 리턴하는 함수
- 일반 함수 앞에 * 을 붙여서 제너레이터 함수를 만듦
- function * gen( ){ yield 1; yield 2; yield 3; }
	- 이런식으로 제너레이터가 있다고 가정했을 때 제너레이터를 실행한 결과는 이터레이터 임
	- let iter = gen( );
	- log( iter.next( ) );
		- 이 이터레이터를 이렇게 실행해 보면 제너레이터를 통해 쉽게 이터레이터를 만들 수 있다는 것을 알 수 있음
	- log( iter[ Symbol.iterator ] );
	- log( iter[ Symbol.iterator ] ( ) == iter );
		- 이 이터레이터는 이터레이터이자 이터러블이기도 한데, 이터레이터는 심볼 이터레이터를 가지고 있고 심볼이터레이터의 실행 결과는 자기 자신
		- 즉, 제너레이터는 웰 폼드 이터레이터를 반환하는 함수
	- for (const a of gen( )) log(a) ; 
		- 이런식으로 순회도 가능
	- function * gen( ){ yield 1; yield 2; yield 3; return 100; }
		- 마지막에 리턴값을 만들 수도 있는데 마지막에 done이 true가 되면서 리턴에서 만든 값 반환
		- 순회할 때는 리턴 값 없이 순회
- 제너레이터를 통해서 어떤 값이든 순회할 수 있는 형태로 조작할 수 있음

- function * odds( ) { yield 1; yield 3; yield 5;  }

	- 0부터 시작해서 혹은 넘겨준 값으로 부터 시작해서 무한히 i++ 을 하면서 해당하는 값을 계속해서 리턴
	- 이 제너레이터를 통해서 생성하는 이터레이터는 let iter3 = infinity( ); iter3.next()를 할 때마다 계속해서 생성할 것

## curry
- 함수를 값으로 다루면서 받아둔 함수를 내가 원하는 시점에 평가시키는 함수

- const curriedAdd = curry((a, b) => a + b);

- const add10 = curriedAdd(10); // 💡 "어? 인자가 하나밖에 없네? 다음 인자 올 때까지 대기할게!"하며 '함수'를 리턴함
	log(add10(5));               // 15 (나중에 5를 주면 그제야 10 + 5 계산 완료)

	// 한 줄로 쓰면 이렇게 됩니다.
	log(curriedAdd(10)(5));      // 15
	

## 총수량, 총가격
```
${go(products,
sum(p => `
<tr>

<td><input type="checkbox" ${p.is_selected ? 'checked':''}></td>

<td>${p.name}</td>

<td>${p.price}</td>

<td><input type="number" value="${p.quantity}"></td>

<td>${p.price * p.quantity}</td>

</tr> `))}
```
- 1. go 함수에 인자 전달하기
	- 컴퓨터가 ${ } 내부의 go(...)를 실행할 때, go 함수에 2개의 인자를 던져줌
	- 첫 번째 인자는 products(상품 객체가 들어있는 배열)
	- 두 번째 인자는 sum(p=>...)
		- 여기서 sum 함수는 curry가 적용되어 있기 때문에 원래 정의된 sum(f, iter)구조로 2개의 인자를 받아야 함에도 p=>라는 함수 1개만 받아도 애러가 발생되지 않음
		- 그러나 sum은 즉시 실행되지 않고 나중에 배열(iter)가 들어오면 그때 계산하도록 대기하는 함수 알맹이 상태로 go에게 전달됨
		- 즉, sum 함수를 실행한 결과값이 go에 인자로 전달되는 것이 아니라 대기 중인 함수가 전달되는 것임
- 2. go 내부에서 데이터의 이동
	- 이제 go 함수의 본체 코드가 실행됨
	- go 내부의 reduce 연산에 의해 첫 번째 인자였던 products 배열이 기준값 a가 됨
	- (...args) => reduce((a, f) => f(a), args);
	- 이 products 배열을 두 번째 인자인 대기 상태의 sum 함수에 매개변수로 주입 -> sum(p=>..., a))
	- const sum = curry((f, iter) => go( iter, map(f), reduce(add)));
	- 결과적으로 컴퓨터 내부에서는 sum(p => ..., products)가 호출되는 것과 같은 상태
- 3. sum 함수 내부에서의 map 연산( 배열 변신 )
	- 이제 실행 주권이 sum 함수 내부로 이동함
	- go( products, map(p => ...), reduce(add) ) 실행됨
	- const map = curry((f, iter) => {let res = []; for(const a of iter){res.push(f(a)); } return res; });
		- 여기서 map역시 curry로 감싸져 있기 때문에 인자 p => ...(f) 하나만 받은 상태에서는 원본 코드가 실행되지 않고 (iter) => {...} 형태의 새로운 함수(대기상태)를 생성하여 리턴
		- 이제 sum 내부의 go 함수 작동 -> go 함수는 첫번째 인자인 products 배열을 들고 다음 순서인 대기 상태의 map 함수를 호출하면서 인자로 밀어 넣음
		- (map(f)) (products)와 같은 형태로 호출이 일어남
	- map 내부의 for of 루프가 products 배열을 순회
	- 배열이 하나씩 함수를 거치면서 5개의 문자열이 담긴 새로운 배열로 변신
- 4. sum 함수 내부의 reduce(add) 연산(문자열 결합)
	- 위에서 만들어진 5개의 문자열 배열이 다음 단계인 reduce로 넘어감
	- reduce 내부 루프가 돌면서 배열의 요소들을 하나씩 축약 함수 add(a, b) => a+b로 처리함
	- 자바스크립틍서 문자열과 문자열을 + 연산하면 공백이나 쉼표 없이 글자라 앞뒤로 길게 이어 붙음
	- 루프가 5번 모두 돌고 나면, 배열 구조는 완전히 파괴되고 하나의 거대한 문자열 덩어리만 남게 됨

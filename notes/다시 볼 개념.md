## 해시테이블의 저장 동작 메서드

```this.arr[this.hashFunction( key )].insertAt(0,new HashData(key,value));}```

- 한 문장으로 정리하면 key와 value를 받아서 key로 위치를 계산하고 그 위치에 해당하는 연결리스트에 (key,value) 데이터를 저장한다.
- this.hashFunction(key)는 입력된 key를 숫자로 변환한  값 -> 0~9 사이의 수 
- this.arr[해시값] 은 hashTable 생성자에서 만들어 둔 구조 -> 해시값에 해당하는 연결리스트를 의미
- .insertAt(0, new HashData(key, value))에서 일단 insertAt 괄호 안에 들어가는 값은 index와 data임 -> 앞에서 정의함
- 그렇다면 0이 인덱스가 되고 뒤에 new HashData(key, value)가 데이터가 되는 것
- new HashData(key, value)이 실제로 저장되는 데이터 객체가 됨
- 해시 테이블은 key만으로 찾고 실제 데이터는 이 객체에 저장

- 전체 동작을 순서도로 표현
- set(42, "hello")
   ↓
  hashFunction(42) → 2 (인덱스 설정)
   ↓
  arr[2] 선택 (연결 리스트)
   ↓
  HashData { key: 42, value: "hello" } 생성
   ↓
  연결 리스트 맨 앞에 삽입
- 따라서 실제로 저장되는 방식은 다음과 같음
  arr[2] = [
  { key: 22, value: "B" },
  { key: 12, value: "A" }]

## 해시테이블의 get 메서드
```get(key){
let currentNode = this.arr[this.hashFunction(key)].head;
while (currentNode !== null){
if (currentNode.data.key === key)
	{return currentNode.data.value;}
 currentNode = currentNode.next;}
return null;} ```
```
- 해시테이블의 조회 동작(get)
- 이 메서드의 역할은 주어진 key에 대응하는 value를 찾아서 반환하는 것, 없으면 null 반환
- let currentNode = this.arr[this.hashFunction(key)].head;
	- 이 한 줄에서 일어나는 일은
	- 먼저 this.hashFunction(key)에서 key를 숫자로 반환 -> 결과 0~9
	- this.arr[해시값] 에서 해당 인덱스의 연결리스트 선택 
	- .head로 그 연결리스트의 첫 번째 노드 선택
	- 즉, key가 들어 있을 가능성이 있는 연결 리스트의 맨 앞 노드부터 탐색하겠다
	- while (currentNode !== null) { 에서 currentNode가 존재하는 동안 반복하고 연결리스트의 끝에 도달하면 null -> 노드가 있는 동안 계속 검사
	- if (currentNode.data.key === key) {  return currentNode.data.value; }에서 currentNode.data.key는 저장된 key를 의미하고 key는 찾고 싶은 key를 의미 -> 둘의 값이 같으면 value를 반환하고 즉시 종료
	- currentNode = currentNode.next; 에서 현재 노드를 버리고 다음 노드로 이동 -> 연결리스트를 순회하며 값을 찾는 것
	- return null; 끝까지 값을 찾지 못했을 경우 -> 해당 해시 인덱스에 key가 존재하지 않음 -> 이 key에 대응하는 값은 없다

## 자바스크립트 스프레드 연산자
-  querySelectorAll은 NodeList 반환 (배열 아님)
- form.querySelectorAll("input") => NodeList [input, input, input] 
-  ... 붙이면 배열로 변환 [...form.querySelectorAll("input")] => [input, input, input] 
- ... 이 바로 스프레드 연산자
- ...은 위치에 따라 이름이 다름
- 배열에서 펼칠 때는 스프레드 연산자로 배열을 낱개로 펼치고
	- 즉 함수를 쓸 때 func(...arg)

	- (...args) => { }
	- 여러 개 들어와도 args하나로 모아서 받음
- 스프레드 연산자는 묶여있는 것을 낱개로 펼친다는 의미다.
- 따라서 위 예시처럼 노드리스트를 배열로 펼치거나( [] ), 객체로 합치거나, 함수인자로 펼칠 때도 많이 쓰인다.

## 자바스크립트 쓰로틀
- 쓰로틀의 목표 
	- --ms 안에는 한 번만 실행
- 쓰로틀을 구현하기 위해 필요한 2가지
	- 마지막으로 실행한 시간 기억하기
	- 지금 시간이랑 비교해서 --ms 지났는지 확인하기 
- 마지막으로 실행한 시간 기억하기
	- let lastTime = 0;
	- 처음엔 0
	- 실행할 때마다 지금 시간으로 업데이트
- 지금 시간 가져오기
	- Date.now()
	- 지금 시간을 숫자로 가져옴
	- ex) 1000, 1100, 1300 ...
- 비교하기
	- Date.now( ) - lastTime >= 300
	- 지금 시간 - 마지막 실행시간 = 얼마나 지났는지
	- 300ms 이상 지났으면 실행
- Date.now( )
	- 현재 시간을 숫자로 표현한 것
- return (...args) => {}
	- 새 함수를 돌려줌
	- 이 새 함수가 실제로 이벤트마다 실행됨
	- 이벤트마다 실행되어야하니까 return안에 있어야함
	- 이벤트마다 return안의 새 함수가 실행됨
- const now = Date.now()
	- 새 함수가 실행될 때마다 지금 시간을 가져옴
	- 호출할 때마다 지금 시간을 가져와야하기 때문에 return안에 있어야함
- lastTime과 비교
	- lastTime = 0
	- now = 1000
	- now - lastTime = 1000 - 0 = 1000 
		- 처음에는 이렇게 됨 => 1000ms 지남
	- lastTime = 1000
	- now - 1100
	- now - lastTime - 1100 - 1000 = 100 
		- 이게 다음 호출 => 100ms 지남
- if (now - lastTime >= delay ){}
	- 지금 시간 - 마지막 실행 시간 >= 300ms
	- 300ms 이상 지났으면 실행

## 화살표함수와 일반함수

	- 여기서 this는 person
	- 따라서 person.hello() 하면 영희가 출력됨
- 화살표 함수 - this가 없음
	- const person = { name:"영희", hello: () => console.log(this.name ) }
	- 화살표 함수에서 this는 존재하지 않기 때문에 person.hello() 하면 undefined가 출력됨
- apply 는 this를 직접 지정해서 함수를 실행하는 메서드
	- 모든 함수가 기본으로 가지고 있는 기능
	- function hello() { console.log(this.name) } 
	- const person = { name: "영희" } hello() 
		- undefined (this 없음) 
	-  hello.apply(person) 
		- "영희" ✅ (this = person 으로 지정)
- apply VS 그냥 호출
	- hello( ) 
		- this = 누가 호출했는지 모름
	- hello.apply( person )
		- this = person으로 강제 지정
	- 인자 전달할 때
		- function hello(a, b) { console.log(this.name, a, b) } hello.apply(person, [1, 2]) // this = person // a = 1, b = 2 
			- 인자를 배열로 넣어야 함
- apply로 호출할 때는 인자를 배열로 넣어야 함
	- hello.apply(person, [1, 2])
	- 여기서 person은 this
	- [1,2]는 배열
	- 배열로 넣는 이유는 그냥 apply가 두 번째 인자를 배열로 받도록 설계되어 있기 때문

## 자바스크립트 정규식
- 문자열에서 패턴을 찾는 도구
- includes는 단순히 있는지 없는지만 알 수 있지만 정규식은 더 복잡한 패턴을 찾을 수 있음
- 정규식 만드는 법
	- 1. 슬래시로 감싸기 
		- /로 시작하고 /로 끝남
		- /안에 찾을 패턴 넣기
		- 예를 들어 /app/
	- 2. new RegExp
		- 문자열로 패턴 넣기
		- 이 방법은 변수도 넣을 수 있음
		- const value = "app"; new RegExp(value)
		- new RegExp("app")
- 정규식 옵션
	- gi 옵션
	- new RegExp("app", "gi")
	- g: 전체에서 찾기
		- g가 없으면 "app apple application".replace(/app/, "❌")  → "❌ apple application" (첫번째만 바꿈)
		- g가 있으면 "app apple application".replace(/app/g, "❌")  → "❌ ❌le ❌lication" (전부 바꿈) ✅
	- i: 대소문자 구분 없이
		- i 없으면 "Apple".replace(/app/, "❌")  → "Apple" (못찾음 ❌)
		- i 있으면 "Apple".replace(/app/i, "❌") → "❌le" (찾음 ✅)
	- 괄호 없이 replace 사용
		- "Apple".replace(/app/gi, "★") 
		- "App" 을 "★" 로 바꿈 // → "★le"
	- 괄호를 사용해서 replace 사용
		- 괄호로 감싸면 찾은 텍스트가 $1에 저장됨
		- "Apple".replace(/(app)/gi, "< mark >$1< /mark >")
		- 1. "(app)"로 "App" 찾음
		- 2. 찾은 "App" $1에 자동 저장
		- 3. "< mark>$1</mark >" = "< mark>App< /mark>"

## 자바스크립트 in과 includes그리고 some 
- in
	- 객체의 키 확인하기
	- 객체에서 사용됨
	- const person = { name: 철수 }
	- name" in person // true → "name" 키가 있음 ✅
	- in은 키만 찾기 때문에 "철수" in person // false → "철수" 는 값이라서 못 찾음 ❌
- includes
	- 배열과 문자열에서 특정 값이 있는지 확인
	- 배열
		- const arr = ["사과", "바나나", "포도"] arr.includes("사과") // true ✅ arr.includes("딸기") // false ❌
	- 문자열
		- "안녕하세요".includes("안녕") // true ✅ "안녕하세요".includes("잘가") // false ❌
- Object.values
	- 값들을 배열로 변환하는 역할
	- const person = { name: "철수", age: 20 }
	- Object.values(person) // → ["철수", 20] // 값들만 뽑아서 배열로!
	- 이제 inclueds 사용가능
	- Object.values(person).includes("철수") // ["철수", 20].includes("철수") // → true ✅
- some
	- 배열에서 조건에 맞는게 하나라도 있으면 true 반환
	- 배열에 기본으로 내장된 메서드
	- 배열.some( ( 요소 ) => 조건 )
	- 여기서 요소는 배열에서 하나씩 꺼내온 값
	- const arr = [1, 2, 3, 4, 5] 
	- arr.some((x) => x > 3) 
		- x에 하나씩 담김 
		- x = 1 → 1 > 3 → false 
		- x = 2 → 2 > 3 → false 
		- x = 3 → 3 > 3 → false 
		- x = 4 → 4 > 3 → true → 찾았다! true 반환 ✅
		- x = 5 → 확인 안 함 (이미 끝났으니까)
		- some 은 true가 나오는 순간 멈춤
		- 하나라도 찾으면 더 볼 필요 없기 때문

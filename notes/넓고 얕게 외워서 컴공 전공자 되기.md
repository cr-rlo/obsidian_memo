## 1비트와 디지털
- 1Bit와 2수(다른 말로 디지털)
	- 1비트란 전기 스위치 1개를 의미
	- 전기가 흐르는 on 상태는 1이다.
	- 전기가 흐르지 않는 off 상태는 0이다.
- 스위치는 on/ off 두가지 경우 -> 2의 n제곱
- 스위치 4개를 조립해서 4비트 -> 2의 4제곱 => 16 => 8 4 2 1
## 4비트와 16진수 그리고 진법변환
- 2진수와 16진수 진법변환
	- 2진수와 16진수를 상호 변환하는 것이 굉장히 중요
	- 4비트는 16진수 한자리 숫자다
	- 16진수는 0~F까지 한 자리에 쓴다
	- 0x F4라고 적혀있으면 16진수 두 숫자니까 4비트 + 4비트 = 8비트
## 16진수 표기가 사용되는 예
- 색상표현 RGB 컬러
	- 한 컬러 당 8비트 사용
	- 전체 경우의 수는 256 -> 0~255
- 컴퓨터 하드웨어 주소 표현
- 메모리 값 표현
## 외워야 할 단위 체계와 숫자
- 외워야 할 단위 체계
	- 8개의 비트를 하나로 묶어 1바이트라고 한다
	- 1 바이트는 영문자 한 글자가 저장될 수 있는 메모리 크기이며 관리의 최소단위
	- 한글 한 글자를 저장하려면 2바이트가 필요하다
	- 4비트는 16가지, 8비트는 256가지, 16비트는 65,536가지
		- 2의 10제곱은 1024
- 컴퓨터 용량을 말하는 단위
	- 1비트
	- 1바이트: 8비트 한 묶음
	- 1킬로 바이트: 1024바이트
	- 1메가 바이트: 1024킬로 바이트
	- 1기가 바이트: 1024메가 바이트
	- 1테라 바이트: 1024기가 바이트
## 컴퓨터가 글자를 다루는 방법
- 숫자를 글자와 매핑 시키자 -> 코드 체계
- 십진수 65 -> 16진수로는 0x41 -> 컴퓨터에겐 영문 대문자 A
- ASCII는 미국에서 사용하는 표준 코드 체계
	- 숫자와 글자를 구별하지 않고 정보를 말 할 때는 바이너리라고 함
## 컴퓨터가 사진을 다루는 방법
- 모니터 화면 상 '점' 하나를 화소라고 함
- 여러 점들을 모아 사진을 만들 수 있음
- 화소 하나를 표현하는데 8비트, 16비트, 24비트, 32비트 정보가 필요할 수 있음
## 디지털 회로와 덧셈(CPU 제작도 가능)
- cpu는 디지털 회로로 이뤄져있음
	- and/ or/ xor/ not
	- xor은 a와 b 인풋의 값이 서로 다를 때 true -> 1
- 컴퓨터가 덧셈하는 방법
	- 2진수 1+1은 2진수 1 0(2)
	- A가 1, B가 1이면 XOR 연산 결과 S는 0이다.
	- 동시에 A가 1, B가 1이면, AND 연산결과 C는 1이다.
	- 이 1은 자리 올림이다.
	- 전가산기/ 반가산기
## 컴퓨터가 뺄셈하는 방법
- 보수
- 6에 4를 더하면 10이다. 즉, 4는 6에 대한 10의 보수이다.
- 13-6은 7이다.
	- 13의 1의 자리에(3) 6에 대한 10의 보수 4를 더하고, 10자리에서 1을 뺴도 역시 7이다.
- 2진수 뺄셈
	- 2의 보수를 구하면 뺄셈 가능
	- 2의 보수는 1의 보수 + 1
- 2진수에서 0은 1로, 1은 0으로 뒤집으면 1의 보수가 됨
- 1의 보수에 1을 더하면 2의 보수
- 어떤 숫자에 2의 보수를 더하면 자동으로 2진수 뺄셈이 됨 -> 단, 자리올림은 버림
## CPU가 곱하고 나누는 방법
- 컴퓨터가 곱하는 방법
	- 4비트로 5를 표현하면 0101이다.
	- 4비트 0101을 왼쪽으로 한 칸 씩 밀면 (shift) 1010이다.
	- 자리 올림은 버린다.
	- 맨 오른쪽에 0이 채워진다.(padding)
	- 4비트로 표현하는 2진수 1010은 10이다.
	- 왼쪽으로 한 칸 밀면 곱하기 2, 두 칸 밀면 곱하기 4가 된다.
- 컴퓨터가 나눗셈하는 방법
	- 4비트로 6을 표현하면 0110이다.
	- 4비트 0110을 오른쪽으로 한 칸씩 밀면 0011이다.
	- 맨 왼쪽에 0이 채워진다. (padding)
	- 4비트로 표현하는 2진수 0011은 3이다.
## 컴퓨터가 연산하는 과정
- CPU는 연산장치 RAM은 메모리(저장)
- RAM에서 정보를 가져옴
- 정보를 레지스터로 옮긴 다음에 ALU를 통해서 연산
- 그 결과를 다시 메모리로 전송

## 컴퓨터가 기억 공간을 관리하는 방법
- 기억장치의 종류와 역할
	- CPU
		- register
		- L1,L2,L3 cache memory
			- cache memory는 속도차 극복을 위해 존재
	- Computer internal(1차 메모리)
		- RAM
	- External storage(2차 메모리)
		- HDD, SSD, USB disk
		- Backup device
- cpu와 ram/ 2차 메모리와 의 속도 차이 
- 1차 메모리는 휘발성이 있음 -> 전원이 꺼지면 메모리가 사라짐
- 밑으로 내려갈수록 속도가 느려지고 가격이 저렴해짐
- 위로 올라갈수록 속도가 빨라지고 가격이 비싸짐
- 컴퓨터가 기억 공간을 관리하는 방법
	- 컴퓨터는 기본적으로 모든 것이 다 숫자이다
	- 정보가 저장된 위치도 숫자로 표시한다
	- 이 같은 관리 체계는 아파트 단지에서 각 가구를 동, 호, 숫자로 관리하는 것과 유사하다.
	- 레지스터, 주 기억장치(RAM), 보조 기억장치(HDD,SSD)를 곤리하는 방법은 조금씩 다르다
	- 레지스터는 개별 기억공간마다 고유 이름을 붙인다.
	- 주 기억 장치는 일련 번호를 붙인다.
	- 보조 기억 장치는 트랙 번호와 섹터 번호를 붙여 관리한다(파일의 등장)
## HDD, SSD와 파일 시스템
- track/ sector을 식별해서 정보 저장
- 파일이 저장되는 방법
	- file allocation table
	- 삭제했을 때 데이터를 지우는 것이 아니라 지워진 상태에 마킹
	- 복원 가능
	- 0번 트랙 0번 섹터는 MBR
		- 운영체제의 부트 코드가 들어감
## 동시성과 병렬성
- 동시성
	- 여러 가지 일이 동시에 진행되는 것
- 병렬성
	- 같은 일을 여러 주체가 함께 동시에 진행하는 것
## 원자성, 동기화 그리고 교착 상태
- 원자성
	- 자원이 선점된 상태인지 확인
	- 그렇지 않으면 내가 선점 + lock
	- 사용이 끝나면 unlock
	- lock을 한 상태에서 unlock을 하는 상태까지, 그 사이 시간동안 원자성 보장
- 동기화
	- 신호등과 잠금장치의 필요성과 유사
	- A일과 B일이 동시에 진행되면서 다른 주체가 동시에 하나의 자원에 접근하려고 하면 -> 동기화라는 행위도 따라 나옴
- 교착상태(Deadlock)
	- 예를 들면 휴지가 없어서 못 나가는 자와 나와야 들어가는 휴지든 자
	- 이러지도 저러지도 못하는 상태
	- 오류 현상

## 국가와 국민으로 이해하는 컴퓨터 세상

## User Mode와 Kernel Mode 그리고 가상화
- OS의 핵심 kernel
	- 컴퓨터라는 국가의 법은 kernel로 구현된다.
	- kernel 영역과 사용자 영역은 완전히 다른 세상이다.
	- 커널은 입출력(I/O)제어 관리
	- 자원 관리 
	- 접근 통제 
- 유저모드와 커널모드
	- 하드웨어를 이루는 가장 핵심적인 장치는 CPU(machine)
	- 하드웨어 계층을 설명할 때 가장 중요한 어휘는 피지컬
		- 물리적인 것으로 하드웨어 수준에서는 설명이 됨
	- 소프트웨어는 로지컬/ 버츄얼
- 플랫폼
	- 다른 것들이 작동할 수 있게 인프라가 되어줌
- 파일
	- 유저모드와 커널 모드를 연결해 주는 인터페이스
	- 커널에서 제공해주는 인터페이스를 통해 커널모드에 접근 -> 파일의 모습을 하고 있음
	- 디바이스 파일
	- '커널의 구성요소에 대한 추상화된 인터페이스를 유저모드에 제공해 줄 때 파일의 형태를 띄고 있다'
- 프로세스는 입출력 주체
- 파일은 대상체
- 프로세스는 파일에 대해서 어떤 권한을 획득해야 함(인터페이스에 대한 접근 권한) -> 그 권한을 부여하는 운영체제
- + 하드웨어를 소프트웨어로 구현해내는 기술이 가상화 기술
## 가상 메모리 소개
- 버츄얼 -> 로지컬
	- 소프트웨어적으로 구현했다.
- 작업관리자
	- 페이징풀
	- 비페이징풀
- 주기억 장치는 RAM. 만약 주기억 장치의 용량보다 더 많은 프로그램을 실행해야 할 경우 메모리 부족으로 실행할 수 없는 것이 아니라 하드디스크의 영역을 끌고 와 RAM인 것 처럼 연결 => 속도는 느려지지만 작동은 됨
- 페이지라는 조각난 단위를 하드디스크와 램 사이를 왔다갔다 하며 공간 이동을 함

- 하나의 프로세스가 실행되면 운영체제가 이 프로세스에게 공간을 부여
- 그 공간을 메모리 공간 즉 VMS
- 만약 이때 동시에 실행되고 있는 프로그램이 있고 그를 실행하기 위해 RAM 영역이 필요한 상황이면, 운영체제가 RAM을 기존에 사용하던 프로그램을 하드로 이사 => 이를 페이지 아웃이라고 함(혹은 스왑 아웃)

- 가상 메모리 영역을 사용하는이유
	- 각 프로세스 공간을 완벽하게 분리하고 통제할 수 있다.
	- 프로세스 오류가 운영체제에 까지 영향을 주지 못하도록 차단할 수 있다.
		- 가상 메모리를 통과해서 메모리를 썼기 때문에 운영체제 자체에 영향을 주지 못할뿐만 아니라 다른 프로그램에 영향을 주는 것도 막을 수 있다.
	- 메모리가 부족해도 여러 프로그램들이 작동하는 등 자원을 효율적으로 활용할 수 있다.

## 컴파일과 고급어 저급어
- high level과 low level의 직역이다.
- 저급어는 기계어이다.
- 기계어는 알아보기 매우 어렵고, 고급어는 인간이 이해하기 쉬운 언어이다.
- 고급어의 코드는 보통 함수 단위로 묶어 표시한다.
- 고급어를 기계어로 바꾸는 것이 번역이다.
- 기계어는 cpu같은 장치가 이해하는 것이라 사람이 이해하기 어려움
	- 기계어를 알아보기 조금 쉬운 형태로 변환한 것이 디스어셈블 코드
- 고급어가 실행되려면 기계어로 번역이 되어야 함(컴파일)
- 네이티브 코드/ 매니지드 코드
	- 네이티브 코드는 cpu나 os에 의존

## 자료를 정리하는 이유
- 어떻게 정리할 것인가
	- 효율 좋은 살람은 정리를 잘 함
	- 지저분한 방을 깨끗하게 정리하는 규칙이 알고리즘
	- 일정 규칙으로 자료를 나열 혹은 정리 하는 것이 자료구조
	- 구조화된 자료에서 원하는 것을 빨리 찾아내는 방법은 알고리즘(문제 해결)
- 자료구조
	- 선형 구조
		- 1차원적 구조
	- 비선형 구조
		- 2차원적 구조
		- 성능이 좋으나 복잡한 구조
## 선형 자료구조(stack과 queue)
- stack
	- 1차원적인 선형 구조
	- 입출력을 할 수 있는 지점이 1개
	- last in first out 구조
	- 처음 넣은 것은 맨 아래 바닥에 깔림
	- 두 번째 부터는 처음 넣은 것 위에 차례로 쌓임
	- 바닥에 있는 것을 꺼내려면 위에 쌓은 것들을 모두 꺼내야 함
	- push/ pop
- queue
	- First in first out 구조
	- 버스를 타기 위해 줄을 서는 것과 같다
	- enqueue/ dequeue
	- 입출력이 양끝에 나눠져있는 구조
	- 동기화와 관련
	- 동시에 일들이 처리되는 것을 효율적으로 관리
